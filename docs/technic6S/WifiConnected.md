# Подключение к Wi-Fi сети

Для подключения Technic6S нужно сделать пару простых действий.

- Вначале, вам нужно будет настроить роутер, к которому будут подключаться ваши дрон и ноутбук для запуска сервер. Если ваш роутер настроен, то вы мо

После настройки роутера выберите варинат подключения:
1. Через кабель-Ethernet.
2. Через точку доступа Technic6S.

---
## 1 способ
Подключите Technic6S к роуетру предварительно посмотрите в какой порт вы подключаете кабель. Порт должен иметь название "LAN", а не "WAN";  после подключения Technic6S к роутеру на orangepi 5 pro(порт Ethernet) должны загореться светодиоды зеленый и желтый. Как загорятся светодиоды зайдите на роутер и в списках клиентов найдите ваш дрон.

После этого подключайтесь к Technic6S по SSH([см. тут](SSH))

Затем, в самом **терминале** прописываем следующие инсталляционные команды:

1. опустим точку доступа Technic6S:
 ```bash
 sudo nmcli connection down technic-ap
 ```

> **Подсказка** если в дальнейшем вам понадобится зайти на дрон через точку доступа, то пропустите 2 пункт 1 способа

2. удаляем точку доступа:
 ```bash
 sudo nmcli connection del technic-ap
 ```
 
 3. выключаем сервис точки доступа:
 ```bash
 sudo systemctl stop hostapd
 ```
 
 4. выключаем auto-start сервиса точки доступа:
 ```bash
 sudo systemctl disable hostapd
 ```
 
 5. теперь надо сменить режим интерфейса:
 ```bash
 sudo ip link set wlan0 down
 sudo iw dev wlan0 set type managed
 sudo ip link set wlan0 up
 ```

6. проверьте, что изменения произошли:
 ```bash
 iw dev
 ```
- Там должно быть словосочетание `type managed`

7. после этого проверьте список Wi-Fi сеток:
 ```bash
 nmcli device wifi list
 ```
- Если вы увидели сеть, которую раздает ваш настроенный роутер, то следуйте дальше

8. Подключение к Wi-Fi сетке:
 ```bash
 sudo nmcli device wifi connect "SSID" password "PASSWORD"
 ```
- `SSID` - это название вашей сети
- `PASSWORD` - это пароль вашей сети
после этого вы увидите, что конект успешен; Ваш дрон готов идти к следующим этапам!

## 2 способ
Данный метод будет работать через системную утилиту `nmtui` и последующее переподключение по-новому ip-адресу дрона.

1. Подключитесь к дрону по точке доступа и зайдите в терминал либо [веб-интерфейса](WebInterface) либо [ssh-подключения](SSH)
2. В самом терминале активируйте утилиту `nmtui` просто её вписав в терминал:
 ```bash
 nmtui
 ```

3. Откроется меню, где нужно будет выбрать `Activate a connection`
> **Подсказка** всё управление происходит через стрелочки на клавиатуре, а чтобы выбрать что-то нужно нажать *enter* или *return* 

- После подключения выходим из данного меню и смотрим нашу статику относительно роутера
4. Введите в терминал комнаду:
 ```bash
 ip a
 ```

- после этой команды найдите такую строчку:
 ```text
4. wlan0-sta: <BROADCAST, MULTICAST, UP, LOWER_UP> ... и тд.
 ```
`192.168.x.x` - будет вашим ip и уже по нему надо будет подключиться по SSH

5. После нахождения нового ip-адреса переподключитесь на него по SSH и проследуйте по пунктам 1 способа с 1 по 4 пункт.
