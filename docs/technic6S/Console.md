# Утилиты для работы с Technic 6S

Для работы с Technic6S предусмотрены несколько новых утилит, которые могут облегчить жизнь

1. Если ползунок на шилде у вас переведен в режим [AUTO](NetworkSettings.md) вы можете изменить имя пользователя или пароль, а также подключиться к общей сети wifi
2. Вы можете сделать запись с экрана с помощью rosbag, для этого нужно нажать на кнопку Начать запись. вы также можете выбрать с какой камеры делать запись экрана, файл будет сохранен в формате .bag
3. Вы сразу можете конвертировать записанный с камеры .bag файл в mp4 формат, этот файл будет сохранен на orangepi и впоследствии может быть выгружен на ноутбук с помощью команды [Scp](CameraScreen.md)
4. В OFFBOARD формате вы можете крутить дрон по yaw прямо из веб-интерфейса
5. В OFFBOARD формате вы можете крутить сервоприводом прямо из веб-интерфейса. Для этого вам нужно выставить шаг, например 400 или 500 и не выходить за границы допустимых значений. Более подробно про сервопривод вы можете почитать [тут](GPIO.md)
