# Technic-Show

**Technic-Show** — это открытая программная платформа для организации роевых шоу дронов. Подходит для работы с полётными контроллерами на прошивке PX4, установленными на дронах линейки Technic6S с вычислительным модулем **Orange Pi 5 Pro**.

Система состоит из двух частей:

- **Клиент (Technic6S)** — программа `technic-show`, которая запускается на Orange Pi, принимает команды от сервера и управляет полётным контроллером через MAVROS.
- **Сервер (персональный компьютер)** — приложение на компьютере оператора (macOS, Windows или Linux), которое отображает состояние всех дронов, отправляет полётные задания, распределяет анимации и позволяет управлять шоу в реальном времени.

Возможности:

- Роевое управление до сотен дронов одновременно.
- Загрузка полётных анимаций в формате CSV (создаются через Blender-аддон)
- Управление светодиодной лентой (WS281x) прямо из анимации.
- Синхронизация времени между дронами через собственный NTP-сервер.
- Работа с локальным позиционированием (ArUco-маркеры, UWB, Optical Flow)
- Обновление прошивки, калибровка сенсоров и загрузка параметров PX4 — прямо из интерфейса сервера.

## Быстрый старт

Если Вам требуется быстро заупстить роевое представление, то посмотрите инструкцию ниже. Прочтите сначала всё инструкцию.

### 1. Скачайте готовый образ

Для Technic6S подготовлен образ, в котором уже установлены:

- Python-зависимости клиента `technic-show`
- chrony, nmcli и др.
- вспомогательные скрипты.

**Ссылка на образ:** *(он находится на этапе тестирования, поэтому воспользуйтесь инструкцией по настройке client в ручную [см. client](Client_installation))*

После скачивания прошейте  **eMMC** при помощи **Balena Etcher** , вставьте её в **Orange Pi** и подайте питание на дрон.

### 2. Подключитесь к дрону по точке доступа

После подключения к дрону [*см. интсрукцию по подключению к wifi*](wifi_connected)

### 3. Старт technic-show
Перейдите в assets:
 ```bash
 cd /home/orangepi/technic-show/builder/assets
 ```

И затем пропишите данные команды:
 ```bash
 chmod +x set_hostname.sh
 ```

затем перейдите в корень проекта:
 ```bash
 cd /home/orangepi/technic-show
 ```

И сделайте:
 ```bash
 chmod +x set_host.py
 chmod +x start_technic_show.sh
 ```

Теперь можно подключиться к серверу:
 ```bash
 sudo ./start_technic_show.sh ip_your_laptop
 ```

### 4. Установка server'а
- Для того, чтобы управлять дроном у нас есть сервер, который можно 
скачать в открытом репозитории githube()
- Полный разбор ПО server [см. тут](Server)

Теперь через пакетный менеджер-pip установить соотвествующие библиотеки
в папке server нужной командой:
 ```bash
 sudo pip3 install -r requirements.txt
 ```
