## 1. Установка с нуля

### 1.1. Требования

- Дрон Technic 6S

### 1.2. Клонирование репозитория

```bash
git clone https://github.com/wdstq4jkwp-oss/technic-show.git
cd technic-show
```

### 1.3. Установка системных зависимостей

```bash
sudo apt-get update
sudo apt-get install -y python3-pip git chrony
sudo pip3 install -r /home/orangepi/technic-show/drone/requirements.txt --upgrade
```

### 1.4. Права на проект

```bash
sudo chown -R orangepi:orangepi /home/orangepi/technic-show
```

## 2. Настройка

### 2.1. Смена имени дрона

Каждому дрону нужно уникальное имя.

```bash
sudo /home/orangepi/technic-show/builder/assets/set_hostname.sh technic-skyris
```

После смены имени перезагрузите дрон:

```bash
sudo reboot
```

### 2.3. Запуск клиента и подключение к серверу

```bash
sudo /home/orangepi/technic-show/start_technic_show.sh ip_your_laptop
```

Где `ip_your_laptop` — IP компьютера с сервером. Узнать его:

- **macOS:** `ipconfig getifaddr en0`
- **Linux:** `ip addr | grep "inet "`
- **Windows:** `ipconfig` — поле «IPv4-адрес»


## 3. Параметры конфигурации `client.ini`

Файл: `/home/orangepi/technic-show/drone/config/client.ini`

### 3.1. Общие настройки

| Параметр | По умолчанию | Что значит |
|----------|--------------|------------|
| `id` | `/hostname` | Имя дрона. Оставляйте `/hostname`. |
| `technic_dir` | `auto` | Путь к ROS-пакету. Не менять. |
| `config_name` | `client` | Идентификатор конфига. Не менять. |
| `config_version` | `1.0` | Версия. Не менять. |

### 3.2. `[SERVER]`

| Параметр | Что значит |
|----------|------------|
| `host` | IP-адрес сервера. Меняется через `start_technic_show.sh`. |
| `port` | Порт. По умолчанию `25000`. |
| `buffer_size` | Размер буфера. `1024`. |

### 3.3. `[BROADCAST]`

| Параметр | Значение | Что значит |
|----------|----------|------------|
| `use` | `False` | **Оставьте `False`.** Отключает автоматический поиск сервера. |
| `port` | `8181` | Не менять. |

### 3.4. `[TELEMETRY]`

| Параметр | Значение | Что значит |
|----------|----------|------------|
| `transmit` | `True` | Отправлять телеметрию на сервер. |
| `frequency` | `1.0` | Частота передачи (раз в секунду). |
| `log_resources` | `False` | Логировать CPU и память. Только для отладки. |

### 3.5. `[FLIGHT]`

| Параметр | Рекомендация для Technic 6S |
|----------|----------------------------|
| `frame_id` | `map` (или `aruco_map`) |
| `takeoff_height` | `1.5` |
| `takeoff_time` | `3.0` |
| `arming_time` | `0.5` |
| `land_delay` | `1.0` |
| `land_timeout` | `8.0` |

### 3.6. `[ANIMATION]`

| Параметр         | Значение    | Что значит               |
| ---------------- | ----------- | ------------------------ |
| `start_action`   | `auto`      | Автовыбор взлёт/полёт.   |
| `check_ground`   | `False`     | **Оставьте `False`.**    |
| `yaw`            | `animation` | Брать рысканье из кадра. |
| `private_offset` | `[0, 0, 0]` | Меняется через сервер.   |

### 3.7. `[LED]`

| Параметр | Значение |
|----------|----------|
| `use` | `True` |
| `takeoff_indication` | `True` |
| `land_indication` | `True` |

### 3.8. `[FAILSAFE]`

Оставьте без изменений.

### 3.9. `[NTP]`

| Параметр | Значение |
|----------|----------|
| `use` | `False` |

## 4. Работа с сервером

### Основные кнопки

| Кнопка | Действие |
|--------|----------|
| **Check selected** | Запросить телеметрию у выбранных дронов. |
| **Start** | Запустить анимацию с задержкой. |
| **Pause** | Пауза / продолжение. |
| **Takeoff** | Взлёт выбранных дронов. |
| **Land** | Посадка. |
| **Disarm** | Остановить моторы. |
| **Flip** | Переворот (в воздухе). |
| **LED Test** | Тест светодиодов (белый). |
| **LED Fill** | Залить ленту цветом. |
| **Emergency Land** | Экстренная посадка. |
| **Reboot FCU** | Перезагрузить полётный контроллер. |
| **Calibrate Gyro** | Калибровка гироскопа. |
| **Calibrate Level** | Калибровка акселерометра. |

### Меню

**File** — отправка анимаций, калибровок, карты ArUco, launch-файлов, параметров PX4, любых файлов и команд.

**Service** — перезапуск `technic`, `technic-show`, `chrony`, перезагрузка дрона, обновление git-репозитория.

**Animation** — привязка начала анимации к текущей позиции, сброс смещений.

**Table** — редактирование конфигов, копирование конфигураций, управление колонками.

### Статус дрона в таблице

- 🟢 зелёный — всё в норме
- 🟡 жёлтый — требует внимания
- 🔴 красный — критическая ошибка, взлёт запрещён


## 5. Полезные команды

| Команда | Что делает |
|---------|-----------|
| `journalctl -u technic-show.service -f` | Логи клиента в реальном времени |
| `systemctl status technic-show.service` | Статус клиента |
| `sudo systemctl restart technic-show.service` | Перезапуск клиента |
| `sudo systemctl restart technic` | Перезапуск ROS-стека |
| `ip a show wlan0` | IP дрона |
| `chronyc sources` | Проверка синхронизации |
| `iw dev wlan0 info` | Режим Wi-Fi |
