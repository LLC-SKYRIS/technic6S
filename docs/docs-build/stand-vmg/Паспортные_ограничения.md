### Паспортные ограничения оборудования

Максимальное допустимое напряжение, ток, тяга, мощность двигателя, размеры винта, точность датчиков и продолжительность непрерывной работы определяются аппаратной версией стенда. Эти значения не заданы в программном коде и должны быть взяты из паспорта конкретного экземпляра.

  
Перед эксплуатацией заполните:

- максимальное входное напряжение: **указать по паспорту**;

- максимальный ток одного канала: **указать по паспорту**;

- максимальную суммарную мощность: **указать по паспорту**;

- диапазон датчика тяги: **указать по паспорту**;

- погрешность измерения напряжения: **указать по паспорту**;

- погрешность измерения тока: **указать по паспорту**;

- погрешность измерения тяги: **указать по паспорту**;

- допустимый диаметр воздушного винта: **указать по паспорту**;

- допустимую длительность непрерывной работы: **указать по паспорту**.


> **Подсказка** Нельзя определять допустимую нагрузку только по диапазонам полей программы.
