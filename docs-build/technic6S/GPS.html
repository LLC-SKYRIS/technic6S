Подключение GPS

При подключении GPS появляются следующие возможности:

  • удерживание коптером позиции при полете на улице;
  • программирование автономных миссий в программе QGroundControl;
  • полеты на глобальные точки в автономном режиме при помощи модуля simple_offboard

Подключение

GPS-модуль подключается к полётному контроллеру двумя кабелями:

  • к разъёму GPS — для приёма координат,

  • к разъёму I2C — для работы встроенного компаса.

После подключения GPS необходимо заново откалибровать компасы в программе QGroundControl. Подключиться к контроллеру можно по Wi-Fi или через USB.

Затем нужно разрешить использование GPS в настройках автопилота:

  • при использовании EKF2 включите GPS в параметре EKF2_AID_MASK,

Если используется LPE, также убедитесь, что компас включён и имеет ненулевой вес — параметр ATT_W_MAGдолжен быть, например, 0.1.
