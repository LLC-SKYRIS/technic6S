Настройка сети

Изменение настроек Wi-Fi точки доступа

  1. Введите в терминал чтобы увидеть настройки сети
sudo nano /etc/hostapd/hostapd.conf
  1. Для изменения имени Wi-Fi точки доступа поменяйте значение параметра ssid
  2. Для изменения пароля Wi-Fi поменяйте значение параметра wpa_passphrase

Подсказка По умолчанию имя точки: technic-xxxx, пароль: technicwifi

  1. После внесенных изменений, нажмите Ctrl+X, затем Y и Enter
  2. Перезапустите OrangePi 5 Pro
sudo reboot
