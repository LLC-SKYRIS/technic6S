Техник шоу

Техник шоу

Техник шоу — это открытая программная платформа для организации роевых шоу дронов. Подходит для работы с полётными контроллерами на прошивке PX4, установленными на дронах линейки Technic6S с вычислительным модулем Orange Pi 5 Pro

Система состоит из двух частей:

  • Клиент (Technic6S) — сервис technic-show.service, который запускается на Orange Pi, принимает команды от сервера и управляет полётным контроллером через MAVROS.
  • Сервер (Персональный Компьютер) — приложение на компьютере оператора (macOS, Windows или Linux), которое отображает состояние всех дронов, отправляет полётные задания, распределяет анимации и позволяет управлять шоу в реальном времени.

Возможности:

  • Роевое управление до сотен дронов одновременно.
  • Загрузка полётных анимаций в формате CSV (создаются через Blender-аддон)
  • Управление светодиодной лентой (WS281x) прямо из анимации.
  • Синхронизация времени между дронами через собственный NTP-сервер.
  • Работа с локальным позиционированием (ArUco-маркеры, UWB, Optical Flow)

3. Старт technic-show

Перейдите в установочную папку:

 cd /home/orangepi/technic-show/builder/assets

И затем дайте права на вспомогательный скрипт по смену имени:

 chmod +x set_hostname.sh

затем перейдите в корень проекта:

 cd /home/orangepi/technic-show

И назначьте стартовые программы:

 chmod +x set_host.py start_technic_show.sh

После всех установок синхронизируйте образ с рабочей директорией:

 sync

Теперь можно подключиться к серверу:

 sudo ./start_technic_show.sh IP

IP - вместе этого вставьте сюда ip-шник вашего ПК, его можно узнать в настройках сети.

4. Установка server'а

Сервер - это приложение, которое можно развернуть на любой ОС, чтобы его установить воспользуйтесь подробной инструкцией тут.

Перейдите в директорию, где у вас лежит файл server.py и запустите его через виртуальное окружение:

 source .venv/bin/activate       # macOS / Linux
 # .venv\Scripts\activate        # Windows

установите зависимости:

 pip install -r requirements.txt

запустите его через python

 python3 server.py
